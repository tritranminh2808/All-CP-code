The codebase is structured around several complex data structures and algorithmic designs, including but not limited to:

*   **Advanced Data Structures:** Segment Trees (ST), Fenwick Trees (BIT), Disjoint Set Union (DSU), Heavy-Light Decomposition (HLD), and Custom Graphs.
*   **Dynamic Programming (DP):** Bitmask DP, Digit DP, DP on Trees, and Knapsack optimizations.
*   **Graph Theory:** Shortest Path algorithms (Dijkstra, Bellman-Ford, Floyd-Warshall), Minimum Spanning Tree (Kruskal, Prim), Network Flow, and Tarjan's Strongly Connected Components.
*   **Mathematics & Number Theory:** Prime Factorization, Modular Inverse, Extended Euclidean Algorithm, Combinatorics, and Matrix Exponentiation.
*   **Search & Sort Techniques:** Binary Search on Answer, Two Pointers, Sliding Window, and Advanced Greedy strategies.

## 🛠️ Compilation & Local Execution

To compile and execute any C++ solution locally with optimizations enabled, use the following standard command template in your terminal:

```bash
# Compile with C++17 standard and O2 optimization flag
g++ -O2 -std=c++17 problem_name.cpp -o problem_name

# Run the executable
./problem_name
```
